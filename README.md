# HEALTHY HABITS - Prenatal Wellness App 🤰

A mobile app designed to help pregnant mothers in Ghana stay active and healthy with safe, guided exercises for all trimesters.

Made with ❤️ for Ghanaian mothers.

## Features
- 🧘‍♀️ Safe prenatal exercises
- 🎥 Guided video demonstrations (offline)
- ⏱️ 2-min quick routines for busy moms
- 💡 Health tips for back pain & swelling
- 📱 Works offline - no data needed

## Exercises Included
1. **Stand & Stretch** - Relieve back pain (2 mins)
2. **Bend Backwards** - Improve posture
3. **Knee Exercises** - Reduce swelling
4. **Leg Stretching** - Improve circulation

All exercises are safe in all trimesters and can be done at home with a chair for support.

## Tech Stack
- React Native / Expo
- expo-video (v2) for local video playback
- React Navigation
